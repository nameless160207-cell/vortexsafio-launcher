# VortexSafio Launcher

Launcher oficial de **VortexSafio 1**, el evento de Minecraft.

Inicia sesión con tu cuenta de Microsoft y entra al evento con un solo clic. El launcher descarga Minecraft, Java y todo lo del evento por su cuenta, y se actualiza solo cuando sale una versión nueva.

## Descargar

En **[la última versión](https://github.com/nameless160207-cell/vortexsafio-launcher/releases/latest)** tienes dos archivos:

- **`VortexSafio-Launcher-Setup-….exe`**: el instalador. Es el recomendado, porque se actualiza solo.
- **`VortexSafio-Launcher-…-portable.exe`**: funciona sin instalar nada, pero no se actualiza solo (avisa cuando hay una versión nueva).

Necesitas Windows 10 u 11 de 64 bits y una cuenta de Microsoft con Minecraft: Java Edition.

Si al abrirlo Windows dice «Windows protegió su PC», pulsa **Más información** y después **Ejecutar de todas formas**. Sale porque el launcher no está firmado con un certificado de pago.
